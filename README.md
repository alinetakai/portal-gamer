Portal Gamer é um site responsivo que adapta sua interface de acordo com o tamanho da tela, orientação do dispositivo e preferências de tema do usuário (modo claro/escuro).  
O design muda dinamicamente, oferecendo uma experiência moderna e visualmente atrativa.

---

## 📝 Descrição
Este projeto demonstra o uso avançado de **media queries**, responsividade e adaptação automática de temas com `prefers-color-scheme`.  
A página apresenta sidebar, cards e um layout que muda com base em **tela pequena**, **tela grande**, **orientação** e **modo escuro**.

---

## 🧠 Aprendizados
- Como usar *media queries* para:
  - telas pequenas  
  - telas grandes  
  - orientação portrait/landscape  
  - tema escuro do sistema  
- Adaptação do layout para múltiplos cenários  
- Organização de componentes com HTML semântico  
- Criação de interfaces responsivas e dinâmicas  

---

## ⚙️ Funcionalidades
- Layout que se adapta a diferentes tamanhos de tela  
- Tema escuro automático conforme o sistema  
- Sidebar visível apenas em telas grandes  
- Cards com estilo gamer em modo paisagem  
- Estrutura visual otimizada para dispositivos móveis  

---

## 🛠️ Stack Utilizada
- **HTML5**  
- **CSS3**  
- **Media Queries** (Responsividade avançada)
